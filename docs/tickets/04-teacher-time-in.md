# 04 — Teacher Time In

**What to build:** Let a signed-in teacher scan the current office QR code to record time in for the workday.

**Blocked by:** 02, 03.

**Status:** ready for live verification

- [ ] A valid scan creates a time-in record for the signed-in teacher and current workday.
- [ ] The system records the scan time automatically; the teacher cannot type or edit it.
- [ ] A teacher can see their own time-in record and cannot see another teacher’s records.
- [ ] An invalid or expired code does not create an attendance record.
- [ ] Works on the live URL.
